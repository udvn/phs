# Medical Risk Assessment Service

Сервис для оценки медицинских рисков на основе пользовательских данных с использованием машинного обучения и экспертных правил.

## Описание

Сервис позволяет пользователю зарегистрироваться, войти, ввести медицинские показатели (возраст, пол, давление, пульс, температура, ИМТ и др.) и получить оценку риска по нескольким биомаркерам. Итоговый риск рассчитывается на основе предсказаний ML-модели (HbA1c, LDL, SBP) и отклонения введённых показателей от нормальных диапазонов. Формируются рекомендации в зависимости от уровня риска.

### Архитектура
- **Backend:** FastAPI (REST API)
- **ML-модель:** Scikit-learn pipeline, загружается из best_model.pkl
- **Frontend:** Streamlit (web-интерфейс)
- **База данных:** PostgreSQL
- **Очередь задач:** RabbitMQ (асинхронные воркеры для расчёта)
- **Контейнеризация:** Docker, Docker Compose

### Как работает сервис
1. Пользователь регистрируется и входит через веб-интерфейс или API.
2. Вводит медицинские показатели через форму.
3. Данные отправляются в API, где:
   - Проверяются и преобразуются в нужный формат.
   - Передаются в ML-модель для предсказания ключевых биомаркеров.
   - Итоговый риск рассчитывается как взвешенное отклонение от нормы с учётом предсказаний модели и введённых данных.
   - Генерируются рекомендации.
4. Результат отображается пользователю, сохраняется история предсказаний.

### Почему такой подход
- Используется гибридная схема: ML-модель для объективных биомаркеров + экспертные правила для прозрачности и расширяемости.
- Все расчёты и хранение истории происходят на сервере, пользователь видит только результат и рекомендации.
- Возможна горизонтальная масштабируемость воркеров для обработки большого числа запросов.

## Быстрый старт

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Убедитесь, что у вас установлен Docker и Docker Compose.
3. Запустите сервис:
   ```bash
   docker-compose up --build
   ```
4. Откройте в браузере:
   - API: [http://localhost:8000/docs](http://localhost:8000/docs)
   - Веб-интерфейс: [http://localhost:8501](http://localhost:8501)

## Тесты

Для запуска простых тестов:
```bash
pytest tests/
```

## Масштабирование воркеров

Чтобы увеличить количество воркеров, измените параметр `replicas` в секции `worker` файла `docker-compose.yml`:
```yaml
  worker:
    deploy:
      replicas: 2  # Можно увеличить
```

## Основные компоненты
- `app/` — исходный код сервиса (API, ML, web, worker)
- `tests/` — простые тесты
- `Dockerfile`, `docker-compose.yml` — инфраструктура
- `best_model.pkl` — обученная ML-модель (pipeline sklearn)

## Пример запроса к API

```bash
curl -X POST "http://localhost:8000/predictions/" \
     -H "Authorization: Bearer <token>" \
     -H "Content-Type: application/json" \
     -d '{"input_data": {"age": 45, "sex": "M", "bmi": 28.5, "systolic_bp": 140, "diastolic_bp": 90, "heart_rate": 85, "temperature": 37.2, "race": "White"}}'
```

Ответ:
```json
{
  "result": {
    "risk_level": "medium",
    "risk_score": 42.5,
    "description": "Средний риск",
    "recommendations": "Необходима консультация врача",
    ...
  }
}
```
